# Sơ đồ Use Case (Use Case Diagram)

Tài liệu này đặc tả các tác nhân (Actors) và danh sách Use Case tương ứng.

## 1. Tác nhân (Actors)
- **Sinh viên (Student)**
- **Cán bộ quản lý (Manager)**
- **Quản trị hệ thống (Admin)**

## 2. Danh sách Use Case theo Tác nhân

### Đối với Sinh viên (Student)
- UC-01: Đăng nhập / Đăng xuất hệ thống
- UC-02: Xem thông tin phòng hiện tại
- UC-03: Gửi đơn đăng ký chỗ ở
- UC-04: Xem hóa đơn dịch vụ hàng tháng
- UC-05: Gửi yêu cầu sửa chữa thiết bị hỏng

### Đối với Cán bộ quản lý (Manager)
- UC-06: Đăng nhập / Đăng xuất
- UC-07: Quản lý dãy nhà và danh sách phòng (CRUD)
- UC-08: Duyệt đơn đăng ký chỗ ở
- UC-09: Xếp phòng cho sinh viên
- UC-10: Quản lý Hợp đồng lưu trú
- UC-11: Nhập chỉ số điện nước & lập hóa đơn hàng tháng

### Đối với Quản trị hệ thống (Admin)
- UC-12: Quản lý tài khoản cán bộ
- UC-13: Cấu hình các tham số hệ thống (Đơn giá điện, nước, loại phòng)
